# D4 招商考察优先级规则 v0.1.0

本模块是可解释、可复算的试行规则，不是落地成功概率、企业投资价值或专家认证结论。输入企业事实、明确的目标环节和评估日期，输出总分、分项分、权重、贡献分、来源、缺失项。与 D2/D3 数据服务分离，不修改企业画像。

## 参考及自主定义的部分

- [pyDecision](https://github.com/Valdecy/pyDecision)：参考其多指标决策及 WSM/SAW 加权汇总方法，不复制源码、不引入整个依赖。
- [OECD 招商机构研究](https://www.oecd.org/content/dam/oecd/en/publications/reports/2018/10/mapping-of-investment-promotion-agencies-in-oecd-countries_3fd8bae0/098e4f0e-en.pdf)：参考按产业优先方向与创新等目标筛选项目的思路。
- 具体分档、权重由本项目按可用字段制定，为演示基线，未经专家或历史招商结果校准；不能归称为上述机构的标准。没有专家成对比较矩阵，因此不宣称使用 AHP；没有连续一致的指标矩阵，因此暂不使用熵权或 TOPSIS。

## 当前规则

唯一配置入口 `src/scoring/rules.json`。权重调整需要修改配置、提升版本并重跑验证；接口不接受任意外部权重。函数层允许传入完整权重用于后续敏感性分析，合计必须为1。

| 分项 | 权重 | 规则 |
| --- | --- | --- |
| 目标环节匹配 | 40% | 与指定环节完全相同为100，否则0。只表示行业匹配，不推断短板或上下游关联 |
| 员工规模 | 20% | 区间下界≤49/99/499/999/1999/更高，对应20/35/55/70/85/100。是规模偏好的初版规则，不代表越大越适合落地 |
| 已收录技术资质 | 25% | 单项冠军100、小巨人90、专精特新75、高新技术企业65、科技型中小企业45，取最高命中项，不叠加。未知资质待补充，不按0判定 |
| 已收录投资事件时效 | 15% | 最近有效事件距评估日≤12/24/36/更久个月，对应100/75/50/25。缺失、无日期、无效日期不评；未来事件排除并提示 |

员工区间和开放区间统一按下界；资质有效期目前没有结构化字段，因此展示为“已收录”，不宣称仍有效。专利数量口径不统一，暂不打分。营收多为区间且缺失较多，注册资本不代表实缴或投资能力，均不打分。地域与生产布局只展示事实。投资事件仅证明已有记录，不代表愿意迁入杭州。

## 分数与缺失

分项分数0–100，贡献=分项×权重，总分为未舍入贡献之和，再四舍五入到两位。没有按候选批次归一化，因此新增企业不改变既有企业分数。单项舍入贡献显示值相加可能与最终值有0.01误差。

缺失分项 `score/contribution=null`，不补成已知0、不重新分配权重。`total_score` 是有证据的贡献下界；有缺失时 `score_kind=evidence_lower_bound`，`score_upper_bound` 是假设缺失项全满分的上界（不是统计置信区间）。`coverage` 是已评项目的权重占比，不是数据真实性概率。页面有缺失时必须显示待补充或分数区间，不能只展示貌似精确的总分。

排名按贡献下界降序、覆盖度降序、ID升序；覆盖不足可能压低排名，不能据此断言企业能力差。先筛出目标环节全部企业再计算全量排序，最后分页。由于先筛选了环节，匹配项在同一列表里恒为100，这是资格匹配分，不是区分企业的主要指标。

## API

沿用 `{code,message,data}` 信封；业务400/404放在信封，参数格式错误由 FastAPI 返回HTTP422。

- `GET /api/v1/scoring/rules`：配置、版本及权重。
- `GET /api/v1/scoring/rankings?target_segment=半导体设备&page=1&page_size=20`：目标环节的排序结果，可加 keyword，大小1–100。
- `GET /api/v1/enterprises/{id}/score?target_segment=半导体设备`：单企业评分。
- 评分接口可加 `as_of=2026-11-25`，固定日期保证复算；省略使用服务当天日期，不声称数据已更新到当天。

每个分项包含 `key,label,score,weight,contribution,status,evidence,reason,source,source_url`。每个结果包含 `rule_version,target_segment,as_of,total_score,score_upper_bound,coverage,score_kind,missing_dimensions,warnings`。详细画像仍使用现有 profile 接口。

## 验证与范围

运行 `python -m unittest discover -s tests -v`。覆盖手算样本、缺失处理、日期异常、资质不叠加、区间解析、权重校验、可复算、全量排序后分页。测试证明实现遵循规则，不证明规则能预测招商效果。

当前数据为50家企业，其中半导体设备3家，多为杭州已有企业。这是企业库筛选与评分演示，不是全国待招商企业名单；还需要外地候选企业、D1补链目标、园区条件及人工校准才能进一步讨论实际落地适配。招商专员前端已接入检索、评分图表、滚动变色与企业详情；D1 诊断入口已由领导看板提供，补链目标与专员检索的跨页联动仍待集成。
